### One specific residual risk for the #16 device pass

`assertVisible: "Saved from YouTube.*"` on the pattern editor reads the notes out
of a `CraftTextField`'s `TextInput`, which carries an `accessibilityLabel`
("Pattern notes"). If the platform exposes only that label and not the field's
value, the assertion fails on a **selector** problem, not on a missing URL —
check `getPatternWithSteps(...).pattern.notes` before filing a product bug. The
same string is asserted directly at the repository layer, so the contract itself
is already pinned; that leg exists only to see it on screen.
